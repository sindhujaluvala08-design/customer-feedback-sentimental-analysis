## Project Scope

This project focuses on analyzing customer feedback and satisfaction data using an interactive dashboard. The dashboard helps understand customer behavior, loyalty levels, purchase frequency, and overall satisfaction through data visualization and business insights.



## Technologies Used

- Python
- Streamlit
- Pandas
- Plotly



## Features

- Interactive Dashboard
- KPI Monitoring
- Customer Satisfaction Analysis
- Loyalty Level Analysis
- Feedback Distribution
- Product vs Service Quality Analysis
- Interactive Filters
- Dataset Download Option
- Login Authentication
